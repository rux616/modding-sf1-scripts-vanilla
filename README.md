# Starfield Scripts

Contains the script sources for vanilla Starfield. Intended to be used as a git submodule.

Tags are in the format `<Identifier_Name>-v<Version>-<SteamBuildID>`, where `<Identifier_Name>` is one of either "CreationKit" or "Starfield", `<Version>` matches the format BGS uses in the Windows executable details (currently "A.B.C.D" format with `A`, `B`, `C`, and `D` being non-negative base-10 numbers), and `<SteamBuildID>` matches the format Steam uses (currently a positive base-10 number).
